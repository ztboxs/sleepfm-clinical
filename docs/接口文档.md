## 1. 概述

SleepFM-Clinical API 基于 SleepFM 多模态睡眠基础模型，提供多导睡眠图 (PSG) 的自动化分析服务，支持以下核心能力：

| 能力 | 说明 |
|------|------|
| **睡眠分期** | 将 PSG 记录逐 5 秒时段分类为 Wake / N1 / N2 / N3 / REM 五种睡眠阶段 |
| **疾病风险预测** | 基于 PSG 嵌入特征 + 人口学信息，预测 1065 种疾病的 Cox 比例风险评分 |

### v2.0 新增特性

| 特性 | 说明 |
|------|------|
| **年龄真实值输入** | 前端输入真实年龄（0~150），后台自动执行 `age / 100` 归一化 |
| **中间产物导出** | 预处理文件 (HDF5)、嵌入文件 (HDF5)、推理结果 (JSON) 均可导出下载 |
| **中间产物复用** | 导出的预处理/嵌入文件可直接作为下一步输入，避免重复计算 |
| **独立睡眠分期接口** | `POST /api/v1/sleep_staging` |
| **独立疾病预测接口** | `POST /api/v1/disease_prediction` |
| **任务状态预检查** | 前端提交前先检查任务状态，避免上传文件后才提示繁忙 |
| **预估剩余时间** | 任务状态接口返回预估剩余时间 |

推理流水线：`EDF 文件上传 → 预处理(重采样/滤波/标准化) → HDF5 → SetTransformer 嵌入 → 下游任务推理`

## 2. 通用说明

### 2.1 请求规范

- 文件上传接口使用 `multipart/form-data` 编码
- 支持 `.edf`、`.hdf5`、`.h5` 格式（视接口而定）

### 2.2 文件传入方式

所有需要文件输入的接口均支持**多种文件传入方式**：

| 方式 | 参数 | 类型 | 说明 |
|------|------|------|------|
| **直接上传** | `file` | `file` | 通过 multipart/form-data 直接上传文件 |
| **URL 下载** | `file_url` | `string` | 提供文件的下载地址，服务端自动下载 |
| **已有文件 ID** | `preprocessed_file_id` / `embedding_file_id` | `string` | 使用之前步骤导出的文件 ID，跳过重复处理 |

### 2.3 年龄参数说明

- **输入**：真实年龄（整数或浮点数），范围 `0 ~ 150`
- **归一化规则**：后台自动执行 `age_normalized = age / 100`
- 不采用 min-max 归一化，不采用 z-score 标准化
- 不使用数据集统计量

### 2.4 响应规范

- 所有响应均为 `application/json` 格式
- 成功响应包含 `"status": "success"` 字段
- 错误响应包含 `"detail"` 字段描述错误原因
- 导出功能返回 `file_id` 和 `download_url` 字段

### 2.5 并发限制

- GPU 推理任务通过全局锁串行执行，同一时刻仅处理一个推理请求
- 提交前可通过 `/api/v1/task_status` 预检查任务状态
- 非 GPU 任务（如健康检查、标签查询、文件下载）不受此限制

### 3.5 EDF 数据预处理

上传 EDF 文件，执行预处理（读取通道、重采样至 128Hz、滤波、标准化），返回通道匹配信息并**导出预处理后的 HDF5 文件**供后续步骤复用。

| 项目 | 说明 |
|------|------|
| **请求方式** | `POST` |
| **请求路径** | `/api/v1/preprocess` |
| **Content-Type** | `multipart/form-data` |

#### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | `file` | 二选一 | 上传 `.edf` 格式文件 |
| `file_url` | `string` | 二选一 | EDF 文件的下载 URL |

#### 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | `string` | `"success"` |
| `channels` | `object` | 按模态分组的通道匹配结果 |
| `duration_seconds` | `float` | 录制时长（秒） |
| `sample_rate` | `integer` | 重采样率 (128 Hz) |
| `preprocessed_file_id` | `string` | 预处理文件 ID，可用于后续步骤 |
| `download_url` | `string` | 预处理文件下载路径 |

#### 响应示例

```json
{
  "status": "success",
  "channels": {
    "BAS": ["C3-A2"],
    "RESP": ["Airflow"],
    "EKG": ["EKG"],
    "EMG": ["Arm EMG"]
  },
  "duration_seconds": 8729.0,
  "sample_rate": 128,
  "preprocessed_file_id": "preproc_a1b2c3d4e5f6",
  "download_url": "/api/v1/download/preproc_a1b2c3d4e5f6"
}
```

### 3.6 生成嵌入向量

接受 EDF 文件、HDF5 文件或预处理文件 ID，通过 SetTransformer 生成嵌入向量，并**导出嵌入文件**供后续步骤复用。

|------|------|

#### 请求参数

| 字段 | 类型 | 必填 | 说明 |

### 3.9 完整推理

上传 EDF 文件，执行完整推理流水线。异步执行，通过轮询获取进度和结果。所有中间产物和最终结果均自动导出。

| 项目 | 说明 |
|------|------|
| **请求方式** | `POST` |
| **请求路径** | `/api/v1/predict` |
| **Content-Type** | `multipart/form-data` |

#### 请求参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `file` | `file` | 二选一 | — | 上传 `.edf` 格式文件 |
| `file_url` | `string` | 二选一 | — | EDF 文件的下载 URL |
| `age` | `float` | 条件必填 | `null` | 真实年龄（0~150），后台自动归一化。当 `tasks` 包含 `disease_prediction` 时必填 |
| `gender` | `integer` | 条件必填 | `null` | 性别编码：`0` = 女性，`1` = 男性 |
| `tasks` | `string` | 否 | `"sleep_staging,disease_prediction"` | 推理任务，逗号分隔 |
| `min_hazard_score` | `float` | 否 | 不过滤 | 疾病风险评分最低阈值 |

#### 结果中的导出字段

完整推理结果（通过 `/api/v1/task_result` 获取）额外包含 `export_ids` 字段：

```json
{
  "export_ids": {
    "preprocessed_file_id": "preproc_xxxxxxxxxxxx",
    "embedding_file_id": "embed_xxxxxxxxxxxx",
    "staging_result_file_id": "staging_xxxxxxxxxxxx",
    "disease_result_file_id": "disease_xxxxxxxxxxxx"
  }
}
```

## 4. 数据流与任务拆解

系统支持将推理流水线拆分为独立子任务，每个子任务可单独执行、输入、输出和保存结果：

```
┌─────────────────────┐
│  EDF 文件上传         │
└──────────┬──────────┘
           ▼
┌─────────────────────┐     导出 HDF5
│  POST /preprocess    │──────────────┐
│  预处理 (EDF→HDF5)   │              │  preprocessed_file_id
└──────────┬──────────┘              ▼
           ▼                   可下载 / 复用
┌─────────────────────┐     导出 HDF5
│  POST /embed         │──────────────┐
│  嵌入生成 (GPU)      │              │  embedding_file_id
│  可传入文件ID跳过预处理│              ▼
└──────────┬──────────┘         可下载 / 复用
           ▼
┌──────────┴──────────┐
▼                     ▼
┌──────────────┐ ┌──────────────────┐
│ POST /sleep_ │ │ POST /disease_   │
│ staging      │ │ prediction       │
│ 睡眠分期     │ │ 疾病风险预测      │
│ 可传入文件ID │ │ 可传入文件ID+年龄 │
└──────┬───────┘ └────────┬─────────┘
       │                  │
       ▼                  ▼
  导出 JSON           导出 JSON
  result_file_id      result_file_id
```

## 6. 错误码说明

| HTTP 状态码 | 含义 | 常见场景 |
|-------------|------|----------|
| `200` | 成功 | 请求正常处理 |
| `400` | 请求参数错误 | 文件格式不对；疾病预测缺少 age/gender；年龄超范围 |
| `404` | 资源不存在 | 文件 ID 不存在或已过期 |
| `422` | 数据处理错误 | EDF 通道不匹配；嵌入生成失败 |
| `500` | 服务器内部错误 | 未预期的异常 |

## 7. 调用示例

### 7.1 curl

**预处理并导出：**

```bash
curl -X POST http://localhost:6006/api/v1/preprocess \
  -F "file=@recording.edf"
# 返回 preprocessed_file_id
```

**用预处理 ID 生成嵌入：**

```bash
curl -X POST http://localhost:6006/api/v1/embed \
  -F "preprocessed_file_id=preproc_a1b2c3d4e5f6"
# 返回 embedding_file_id
```

**用嵌入 ID 做睡眠分期：**

```bash
curl -X POST http://localhost:6006/api/v1/sleep_staging \
  -F "embedding_file_id=embed_a1b2c3d4e5f6"
```

**用嵌入 ID 做疾病预测：**

```bash
curl -X POST http://localhost:6006/api/v1/disease_prediction \
  -F "embedding_file_id=embed_a1b2c3d4e5f6" \
  -F "age=45" \
  -F "gender=1"
```

**完整推理：**

```bash
curl -X POST http://localhost:6006/api/v1/predict \
  -F "file=@recording.edf" \
  -F "age=45" \
  -F "gender=1" \
  -F "tasks=sleep_staging,disease_prediction"
```

**下载导出文件：**

```bash
curl -O http://localhost:6006/api/v1/download/preproc_a1b2c3d4e5f6
```

**提交前检查任务状态：**

```bash
curl http://localhost:6006/api/v1/task_status
```

### 7.2 Python (requests)

```python
import requests

BASE_URL = "http://localhost:6006"

# 1. 预处理
with open("recording.edf", "rb") as f:
    r = requests.post(f"{BASE_URL}/api/v1/preprocess",
                      files={"file": ("recording.edf", f)})
preproc_id = r.json()["preprocessed_file_id"]

# 2. 用预处理 ID 生成嵌入（跳过 EDF 读取）
r = requests.post(f"{BASE_URL}/api/v1/embed",
                  data={"preprocessed_file_id": preproc_id})
embed_id = r.json()["embedding_file_id"]

# 3. 用嵌入 ID 做睡眠分期
r = requests.post(f"{BASE_URL}/api/v1/sleep_staging",
                  data={"embedding_file_id": embed_id})
staging = r.json()["sleep_staging"]

# 4. 用嵌入 ID 做疾病预测
```

## 8. 附录：EDF 文件兼容性要求

### 通道匹配规则

模型要求 EDF 文件包含 **全部四种模态** 的通道，每种模态至少匹配 1 个通道：

| 模态 | 说明 | 常见匹配通道名示例 |
|------|------|-------------------|
| **BAS** | 脑电 (EEG) / 眼电 (EOG) | `C3-A2`, `C4-A1`, `F3-M2`, `O1-M2`, `EOG(L)`, `EOG(R)` |
| **RESP** | 呼吸相关 | `Airflow`, `SpO2`, `Chest`, `Abd`, `Nasal`, `Pulse` |
| **EKG** | 心电 | `EKG`, `ECG`, `ECG II`, `ECG1` |
| **EMG** | 肌电 | `EMG`, `Arm EMG`, `Chin`, `Chin EMG`, `LEG(L)`, `LEG(R)` |

通道名匹配区分大小写，完整支持列表见 `sleepfm/configs/channel_groups.json`。

### 推荐测试文件

项目自带 `notebooks/demo_data/demo_psg.edf`：
- 通道：`C3-A2`, `Airflow`, `Arm EMG`, `EKG`（四种模态齐全）
- 时长：约 8729 秒（~2.4 小时）
- 人口学参数：`age=3`（真实年龄），`gender=0`
