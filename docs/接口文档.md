# SleepFM-Clinical API 接口文档

> 基础地址：`http://<host>:6006` · Swagger：`/docs` · ReDoc：`/redoc`

## 调用约定

- 文件请求使用 `multipart/form-data`，响应一般为 JSON。
- `age` 填 0–150 的真实年龄，服务端执行 `age / 100`；`gender`：`0` 女性、`1` 男性。
- 独立推理接口使用“提交任务 → 按任务 ID 轮询”的异步协议。
- 完整推理 `/predict` 使用单独的全局状态 `/task_status` 和一次性结果 `/task_result`。
- GPU 阶段由进程内锁串行执行；子任务可能已受理但仍在等待 GPU。

## 接口总览

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/health` | 服务、模型、GPU 与内存状态 |
| GET | `/api/v1/task_status` | 完整推理进度 |
| GET | `/api/v1/task_result` | 读取一次完整推理结果 |
| GET | `/api/v1/subtask_result/{task_id}` | 轮询独立子任务结果 |
| GET | `/api/v1/label_mapping` | 疾病标签映射 |
| POST | `/api/v1/preprocess` | EDF 预处理 |
| POST | `/api/v1/embed` | 生成嵌入 |
| POST | `/api/v1/sleep_staging` | 独立睡眠分期 |
| POST | `/api/v1/disease_prediction` | 独立疾病预测 |
| POST | `/api/v1/predict` | 完整推理 |
| GET | `/api/v1/download/{file_id}` | 下载临时导出文件 |
| GET | `/api/v1/docs` | 列出网站可阅读的文档 |
| GET | `/api/v1/docs/{name}` | 返回指定 Markdown 原文 |

## 状态与基础数据

### 健康检查

```bash
curl http://<host>:6006/api/v1/health
```

关键响应：

```json
{
  "status": "healthy",
  "gpu": {"name": "NVIDIA GPU", "memory_total_mb": 24564},
  "ram": {"total_mb": 65536, "used_mb": 12000, "available_mb": 53536},
  "models_loaded": {
    "base_model": true,
    "sleep_staging_model": true,
    "disease_prediction_model": true
  }
}
```

### 完整推理状态与结果

`GET /api/v1/task_status` 返回 `active`、`stage`、`stage_label`、`progress_pct`、耗时、预计剩余时间、错误和 `has_result`。当 `active=false` 且 `has_result=true` 时调用：

```bash
curl http://<host>:6006/api/v1/task_result
```

结果是一次性读取：第二次调用会返回 `no_result`。若任务未完成返回 `processing`，失败返回 `error`。

### 疾病标签

`GET /api/v1/label_mapping` 返回：

```json
{
  "total": 1065,
  "mappings": [
    {"label_idx": 0, "phecode": "...", "phenotype": "..."}
  ]
}
```

## 独立子任务协议

以下四个 POST 接口均立即返回受理结果，不会同步返回模型结果：

```json
{"status": "accepted", "task_id": "sub_xxxxxxxxxxxx"}
```

轮询同一个任务 ID：

```bash
curl http://<host>:6006/api/v1/subtask_result/{task_id}
```

轮询响应：

```json
{"status": "running"}
```

成功时返回 `status: success` 和接口对应结果；失败时返回 `{"status":"error","detail":"..."}`。成功或失败结果读取后即删除，再次查询返回 404。建议 1–3 秒轮询一次并设置客户端超时。

### EDF 预处理

`POST /api/v1/preprocess`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 二选一 | `.edf` 文件 |
| `file_url` | 二选一 | 服务端可访问的 EDF URL |

```bash
curl -X POST http://<host>:6006/api/v1/preprocess \
  -F "file=@recording.edf"
```

成功轮询结果包含 `channels`、`duration_seconds`、`sample_rate: 128`、`preprocessed_file_id` 和 `download_url`。

### 生成嵌入

`POST /api/v1/embed`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 三选一 | EDF、HDF5 或 H5 |
| `file_url` | 三选一 | 服务端可访问的文件 URL |
| `preprocessed_file_id` | 三选一 | 复用本服务导出的预处理文件 |

```bash
curl -X POST http://<host>:6006/api/v1/embed \
  -F "preprocessed_file_id=preproc_xxxxxxxxxxxx"
```

成功轮询结果包含各模态 `embeddings.shape`、`embed_dim`、`embedding_file_id` 和 `download_url`。

### 独立睡眠分期

`POST /api/v1/sleep_staging`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 三选一 | 嵌入 HDF5/H5 或 EDF |
| `file_url` | 三选一 | 文件 URL |
| `embedding_file_id` | 三选一 | 复用本服务导出的嵌入 |

```bash
curl -X POST http://<host>:6006/api/v1/sleep_staging \
  -F "embedding_file_id=embed_xxxxxxxxxxxx"
```

成功轮询结果包含 `sleep_staging`、`result_file_id` 和 JSON `download_url`。

### 独立疾病预测

`POST /api/v1/disease_prediction`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `file` / `file_url` / `embedding_file_id` | 三选一 | EDF、嵌入文件或已有嵌入 ID |
| `age` | 是 | 真实年龄 0–150 |
| `gender` | 是 | 0 女性，1 男性 |
| `min_hazard_score` | 否 | 过滤返回列表的最低分数 |

```bash
curl -X POST http://<host>:6006/api/v1/disease_prediction \
  -F "embedding_file_id=embed_xxxxxxxxxxxx" \
  -F "age=45" -F "gender=1"
```

成功轮询结果包含 `disease_prediction`、`result_file_id` 和 JSON `download_url`。

## 完整推理

`POST /api/v1/predict` 接受 `file` 或 `file_url` 形式的 EDF。

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` / `file_url` | 二选一 | — | EDF 上传或 URL |
| `tasks` | 否 | `sleep_staging,disease_prediction` | 逗号分隔的任务名 |
| `age` | 条件必填 | — | 包含疾病预测时必填，真实年龄 |
| `gender` | 条件必填 | — | 包含疾病预测时必填 |
| `min_hazard_score` | 否 | — | 疾病结果过滤阈值 |

```bash
curl -X POST http://<host>:6006/api/v1/predict \
  -F "file=@recording.edf" \
  -F "age=45" -F "gender=1" \
  -F "tasks=sleep_staging,disease_prediction"
```

受理响应：

```json
{
  "status": "accepted",
  "message": "推理任务已提交，请通过 /api/v1/task_status 查询进度"
}
```

已有完整推理时返回 HTTP 200 与 `status: busy`。完成后从 `/api/v1/task_result` 取得 `sleep_staging`、`disease_prediction` 及：

```json
{
  "export_ids": {
    "preprocessed_file_id": "preproc_xxxxxxxxxxxx",
    "embedding_file_id": "embed_xxxxxxxxxxxx",
    "staging_result_file_id": "staging_xxxxxxxxxxxx",
    "disease_result_file_id": "disease_xxxxxxxxxxxx"
  }
}
```

```json

  "top_risks": [{
    "rank": 1,
    "label_idx": 746,
```

## 文件下载与复用

```bash
curl -OJ http://<host>:6006/api/v1/download/{file_id}
```

导出 HDF5 或 JSON 保存在服务端 `exports/`。下载接口会清理修改时间超过 24 小时的文件；不存在或已过期返回 404。调用方应及时下载，或在有效期内把 `preprocessed_file_id` / `embedding_file_id` 传给下一步。

## 文档读取接口

```bash
curl http://<host>:6006/api/v1/docs
curl http://<host>:6006/api/v1/docs/%E6%A8%A1%E5%9E%8B%E7%AE%97%E6%B3%95
```

列表接口返回 `documents[]`，每项包含 `name`、Markdown 首个一级标题 `title` 和 `url`。详情接口只允许读取发布白名单中的文档，返回 `text/markdown`；不存在的名称返回 404。

## Python 异步轮询示例

```python
import time
import requests

BASE_URL = "http://<host>:6006"

def wait_subtask(task_id, timeout=600):
    deadline = time.time() + timeout
    while time.time() < deadline:
        result = requests.get(
            f"{BASE_URL}/api/v1/subtask_result/{task_id}", timeout=30
        ).json()
        if result["status"] == "success":
            return result
        if result["status"] == "error":
            raise RuntimeError(result["detail"])
        time.sleep(2)
    raise TimeoutError(task_id)

with open("recording.edf", "rb") as file:
    submitted = requests.post(
        f"{BASE_URL}/api/v1/preprocess",
        files={"file": ("recording.edf", file)},
        timeout=120,
    ).json()

preprocessed = wait_subtask(submitted["task_id"])
print(preprocessed["preprocessed_file_id"])
```

## 错误与输入要求

| 状态/结果 | 常见原因 | 处理 |
| --- | --- | --- |
| HTTP 400 | 格式错误、缺少文件、年龄超范围 | 检查表单参数 |
| HTTP 404 | 任务/文档/文件 ID 不存在或已过期 | 使用本次返回的 ID 重试 |
| HTTP 422 | FastAPI 表单校验失败 | 按 Swagger 检查字段类型 |
| `status: error` | 后台预处理或推理失败 | 查看 `detail`，检查通道和模型日志 |
| `status: busy` | 已有完整推理 | 轮询全局任务后再提交 |

当前嵌入流程要求 EDF 至少各匹配一个 BAS、RESP、EKG、EMG 通道。通道名区分大小写，支持列表以 `sleepfm/configs/channel_groups.json` 为准。
