## 2. 通过 Web 界面测试

浏览器访问：`http://<服务器IP>:6006/`

### 2.1 检查系统状态

1. 点击 **系统状态** 标签页
2. 确认三个模型均显示 **已加载**
3. 确认 GPU 信息正常

### 2.2 完整推理测试

1. 点击 **完整推理** 标签页
2. 上传 `notebooks/demo_data/demo_psg.edf`
3. 填写参数：
   - 年龄：`3`（真实年龄，后台自动归一化）
   - 性别：`女性 (0)`
4. 勾选：**睡眠分期** + **疾病风险预测**
5. 点击 **开始推理**
6. 等待完成（约 30-60 秒），查看结果：
   - **睡眠分期**：查看各阶段分布，点击阶段卡片可筛选
   - **疾病风险**：查看排名
   - **导出按钮栏**：下载预处理/嵌入/结果文件

### 2.3 数据预处理 + 文件复用

1. 点击 **数据预处理** 标签页
2. 上传 `demo_psg.edf`
3. 点击 **开始预处理**
4. 查看结果后，点击 **下载预处理文件 (HDF5)**
5. 点击 **用于下一步（生成嵌入）** → 自动跳转到嵌入页面

### 2.4 生成嵌入 + 文件复用

1. 在 **生成嵌入** 页面，选择「已有文件 ID」模式
2. 输入上一步的 `preprocessed_file_id`（已自动填入）
3. 点击 **生成嵌入** → 跳过 EDF 预处理，直接生成嵌入
4. 点击 **用于睡眠分期** 或 **用于疾病预测** 跳转

### 2.5 独立睡眠分期

1. 点击 **睡眠分期** 标签页
2. 选择「已有文件 ID」模式，输入 `embedding_file_id`
3. 点击 **开始睡眠分期**
4. 查看结果，点击阶段卡片可筛选
5. 点击 **导出结果 (JSON)** 下载

### 2.6 独立疾病预测

1. 点击 **疾病预测** 标签页
2. 选择「已有文件 ID」模式，输入 `embedding_file_id`
3. 填写年龄：`3`，性别：`女性 (0)`
4. 点击 **开始疾病预测**
5. 查看结果，点击 **导出结果 (JSON)** 下载

### 2.7 睡眠阶段筛选

在睡眠分期结果页面：
- 点击任一阶段卡片（清醒/N1/N2/N3/REM）→ 只显示该阶段的 epoch
- 再次点击同一卡片 → 取消筛选
- 点击 **清除筛选** 按钮 → 恢复显示全部

### 2.8 任务繁忙预检查

如果已有一个推理任务正在执行：
- 点击 **开始推理** 时，前端会先检查任务状态
- 立即弹出提示（显示当前文件、阶段、进度、已运行时间、预估剩余时间）
- 无需等待文件上传完成

## 3. 通过命令行 (curl) 测试

### 3.1 检查任务状态（提交前预检查）

```bash
curl http://localhost:6006/api/v1/task_status | python3 -m json.tool
```

### 3.2 预处理并获取文件 ID

```bash
curl -X POST http://localhost:6006/api/v1/preprocess \
  -F "file=@notebooks/demo_data/demo_psg.edf"
# 记录返回的 preprocessed_file_id
```

### 3.3 用预处理文件 ID 生成嵌入

```bash
curl -X POST http://localhost:6006/api/v1/embed \
  -F "preprocessed_file_id=preproc_xxxxxxxxxxxx"
# 记录返回的 embedding_file_id
```

### 3.4 独立睡眠分期

```bash
curl -X POST http://localhost:6006/api/v1/sleep_staging \
  -F "embedding_file_id=embed_xxxxxxxxxxxx"
```

### 3.5 独立疾病预测

```bash
curl -X POST http://localhost:6006/api/v1/disease_prediction \
  -F "embedding_file_id=embed_xxxxxxxxxxxx" \
  -F "age=3" \
  -F "gender=0"
```

  -F "file=@notebooks/demo_data/demo_psg.edf" \

  -F "gender=0" \
  -F "tasks=sleep_staging,disease_prediction"

## 4. 通过 Python 脚本测试

```python
import requests
import time

BASE_URL = "http://localhost:6006"
EDF_PATH = "notebooks/demo_data/demo_psg.edf"

# 0. 检查任务状态
r = requests.get(f"{BASE_URL}/api/v1/task_status")
ts = r.json()
if ts["active"]:
    print(f"任务繁忙：{ts['stage_label']}，进度 {ts['progress_pct']}%")
    exit()

# 1. 预处理
with open(EDF_PATH, "rb") as f:
    r = requests.post(f"{BASE_URL}/api/v1/preprocess",
                      files={"file": ("demo_psg.edf", f)})
preproc = r.json()
print(f"预处理完成，file_id: {preproc['preprocessed_file_id']}")

# 2. 用文件 ID 生成嵌入（跳过 EDF 预处理）
r = requests.post(f"{BASE_URL}/api/v1/embed",
                  data={"preprocessed_file_id": preproc["preprocessed_file_id"]})
embed = r.json()
print(f"嵌入生成完成，file_id: {embed['embedding_file_id']}")

# 3. 独立睡眠分期
r = requests.post(f"{BASE_URL}/api/v1/sleep_staging",
                  data={"embedding_file_id": embed["embedding_file_id"]})
staging = r.json()
ss = staging["sleep_staging"]
print(f"睡眠分期: {ss['total_epochs']} epochs")
for stage, info in ss["summary"].items():
    print(f"  {stage}: {info['count']} ({info['percentage']}%)")

# 4. 独立疾病预测（年龄输入真实值）
r = requests.post(f"{BASE_URL}/api/v1/disease_prediction",
                  data={"embedding_file_id": embed["embedding_file_id"],
                        "age": 3, "gender": 0})
disease = r.json()
dp = disease["disease_prediction"]
print(f"\nTop 5 disease risks:")
for risk in dp["top_risks"][:5]:
    print(f"  #{risk['rank']} {risk['phenotype']} ({risk['hazard_score']:.4f})")

# 5. 下载嵌入文件
r = requests.get(f"{BASE_URL}/api/v1/download/{embed['embedding_file_id']}")
with open("exported_embedding.hdf5", "wb") as f:
    f.write(r.content)
print(f"\n嵌入文件已下载: exported_embedding.hdf5")
```

## 5. 常见问题

### Q1: age 参数怎么填？

v2.0 起输入**真实年龄**，如 45 岁填 `45`。demo 数据对应约 3 岁。

### Q2: 如何避免重复预处理？

使用预处理或嵌入步骤返回的 `file_id` 传入后续接口：
- `preprocessed_file_id` → 跳过 EDF 读取
- `embedding_file_id` → 直接做睡眠分期/疾病预测

### Q3: 导出文件多久过期？

24 小时后自动清理。建议及时下载保存。
