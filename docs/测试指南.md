# SleepFM-Clinical 测试指南

## 测试前提

本指南用于服务部署后的验收。确认服务器已按部署文档启动，并准备仓库演示文件 `notebooks/demo_data/demo_psg.edf`。

| 项目 | Demo 值 |
| --- | --- |
| 通道 | `C3-A2`、`Airflow`、`Arm EMG`、`EKG` |
| 模态 | BAS、RESP、EMG、EKG |
| 原始采样率 | 256 Hz |
| 时长 | 约 8729 秒（约 2.4 小时） |
| 年龄 | `3`（真实年龄） |
| 性别 | `0`（女性） |

先检查服务：

```bash
curl http://<host>:6006/api/v1/health
```

预期 `status` 为 `healthy`，`models_loaded` 三项均为 `true`。

## 网页验收

### 完整推理

1. 打开 `http://<host>:6006/`，进入“完整推理”。
2. 上传 `notebooks/demo_data/demo_psg.edf`。
3. 年龄填 `3`，性别选“女性 (0)”，勾选睡眠分期和疾病预测。
4. 提交后观察顶栏进度，等待结果区出现睡眠阶段分布、疾病风险排序和导出按钮。
5. Demo 通常约 30–60 秒完成；硬件、文件时长、磁盘与任务等待会影响耗时。

### 分步调用与文件复用

1. 在“数据预处理”上传 Demo，确认采样率变为 128 Hz、四组模态均有匹配通道。
2. 记录 `preprocessed_file_id`，跳转“生成嵌入”并使用已有文件 ID。
3. 记录 `embedding_file_id`，分别进入“睡眠分期”和“疾病预测”复用。
4. 疾病预测填写年龄 `3`、性别 `0`。
5. 下载预处理 HDF5、嵌入 HDF5 和两个结果 JSON，确认文件非空。

### 系统与标签

- “系统状态”：确认模型、GPU、内存信息可见，任务完成后恢复空闲。
- “疾病标签”：确认列表可加载并能展示 `label_idx`、PheCode、疾病名称。
- 睡眠分期结果：点击 Wake/N1/N2/N3/REM 卡片，确认筛选和清除筛选有效。

### 文档中心

1. 在控制台顶栏选择“帮助” → “使用文档”。
2. 确认地址进入 `/help`，页面左侧显示六份文档。
3. 依次切换“使用文档、模型算法、训练与调优、接口文档、部署文档、测试指南”。
4. 确认右侧正文更新，至少一个代码块和表格能正确渲染。
5. 点击“返回控制台”回到 `/`，点击“API 参考”进入 `/docs`。

## curl 验收

### 独立子任务规则

四个独立接口提交后都应先返回：

```json
{"status": "accepted", "task_id": "sub_xxxxxxxxxxxx"}
```

使用响应中的 ID 轮询：

```bash
curl http://<host>:6006/api/v1/subtask_result/{task_id}
```

看到 `running` 时等待后重试；看到 `success` 时保存结果；看到 `error` 时记录 `detail`。最终结果读取后会删除，不要再次轮询同一任务 ID。

### 预处理

```bash
curl -X POST http://<host>:6006/api/v1/preprocess \
  -F "file=@notebooks/demo_data/demo_psg.edf"
```

轮询成功后检查 `channels` 四组非空、`sample_rate=128`，并记录 `preprocessed_file_id`。

### 生成嵌入

```bash
curl -X POST http://<host>:6006/api/v1/embed \
  -F "preprocessed_file_id=preproc_xxxxxxxxxxxx"
```

轮询成功后检查 BAS/RESP/EKG/EMG 的第二维为 128，并记录 `embedding_file_id`。

### 睡眠分期

```bash
curl -X POST http://<host>:6006/api/v1/sleep_staging \
  -F "embedding_file_id=embed_xxxxxxxxxxxx"
```

轮询成功后检查 `total_epochs > 0`、五类汇总均存在、各概率位于 0–1。

### 疾病预测

```bash
curl -X POST http://<host>:6006/api/v1/disease_prediction \
  -F "embedding_file_id=embed_xxxxxxxxxxxx" \
  -F "age=3" -F "gender=0"
```

轮询成功后检查 `all_hazards_count=1065`，每个风险项含排名、标签、名称和 `hazard_score`。

### 完整推理

```bash
curl -X POST http://<host>:6006/api/v1/predict \
  -F "file=@notebooks/demo_data/demo_psg.edf" \
  -F "age=3" -F "gender=0" \
  -F "tasks=sleep_staging,disease_prediction"
```

预期受理响应包含 `"status": "accepted"`。之后轮询并读取一次结果：

```bash
curl http://<host>:6006/api/v1/task_status
curl http://<host>:6006/api/v1/task_result
```

仅在 `task_status` 显示任务已结束且 `has_result=true` 后调用 `/api/v1/task_result`。检查 `export_ids` 包含预处理、嵌入和所选下游结果 ID。

### 下载与文档接口

```bash
curl -OJ http://<host>:6006/api/v1/download/embed_xxxxxxxxxxxx
curl http://<host>:6006/api/v1/docs
curl http://<host>:6006/api/v1/docs/%E4%BD%BF%E7%94%A8%E6%96%87%E6%A1%A3
```

确认下载文件非空；文档列表有六项，详情响应以 `# SleepFM-Clinical 使用文档` 开头。

## Python 端到端示例

```python
import time
import requests

BASE_URL = "http://<host>:6006"
EDF_PATH = "notebooks/demo_data/demo_psg.edf"

def submit(path, *, files=None, data=None):
    response = requests.post(
        f"{BASE_URL}{path}", files=files, data=data, timeout=120
    )
    response.raise_for_status()
    result = response.json()
    assert result["status"] == "accepted"
    return result["task_id"]

def wait(task_id, timeout=600):
    deadline = time.time() + timeout
    while time.time() < deadline:
        response = requests.get(
            f"{BASE_URL}/api/v1/subtask_result/{task_id}", timeout=30
        )
        response.raise_for_status()
        result = response.json()
        if result["status"] == "success":
            return result
        if result["status"] == "error":
            raise RuntimeError(result["detail"])
        time.sleep(2)
    raise TimeoutError(task_id)

with open(EDF_PATH, "rb") as file:
    task_id = submit(
        "/api/v1/preprocess",
        files={"file": ("demo_psg.edf", file)},
    )
preprocessed = wait(task_id)

task_id = submit(
    "/api/v1/embed",
    data={"preprocessed_file_id": preprocessed["preprocessed_file_id"]},
)
embedded = wait(task_id)

task_id = submit(
    "/api/v1/sleep_staging",
    data={"embedding_file_id": embedded["embedding_file_id"]},
)
staging = wait(task_id)
assert staging["sleep_staging"]["total_epochs"] > 0

task_id = submit(
    "/api/v1/disease_prediction",
    data={
        "embedding_file_id": embedded["embedding_file_id"],
        "age": 3,
        "gender": 0,
    },
)
disease = wait(task_id)
assert disease["disease_prediction"]["all_hazards_count"] == 1065
```

## 异常用例

| 用例 | 预期 |
| --- | --- |
| 年龄为 `-1` 或 `151` | HTTP 400 |
| 疾病任务不传年龄/性别 | HTTP 422 或完整推理 HTTP 400 |
| 上传非 EDF 到预处理 | HTTP 400 |
| 使用不存在的文件 ID | HTTP 404 |
| 查询不存在/已消费的任务 ID | HTTP 404 |
| EDF 缺少任一必需模态 | 子任务返回 `status: error` 和通道详情 |
| 完整推理运行时再次提交 | HTTP 200、`status: busy` |
| 文档名称不在发布白名单 | HTTP 404 |
