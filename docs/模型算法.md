# SleepFM-Clinical 模型算法说明

## 模型定位

SleepFM 是面向多导睡眠监测（PSG）的多模态基础模型。本服务在其公开代码与模型结构上封装 EDF 预处理、表征生成、五分类睡眠分期和疾病风险排序。它用于科研与辅助分析，不替代医生诊断、人工质控或经监管审批的医疗器械。

## 输入与预处理

输入 EDF 中的信号按通道名映射为四组：BAS（脑电/眼电等基础信号）、RESP（呼吸）、EKG（心电）、EMG（肌电）。服务将信号重采样为 128 Hz，并转为 HDF5。每个 5 秒片段包含 640 个采样点，作为基座模型的一个时间 Token。

公开论文强调对不同 PSG montage 和通道组合的适应能力；但当前服务的数据集装载逻辑要求 BAS、RESP、EKG、EMG 四类均至少匹配一个通道，否则会在嵌入阶段拒绝处理。

## 基座模型

### 5 秒 Tokenizer

每个单通道 5 秒窗口进入六个一维卷积块，通道数依次为 `1→4→8→16→32→64→128`。卷积块包含 Conv1d、归一化和 ELU，随后使用自适应平均池化与线性层生成 128 维嵌入。相同 Tokenizer 可处理不同生理通道，不依赖固定导联顺序。

### 通道无关与时序建模

模型先在同一时刻对可用通道做带掩码的注意力池化，再加入位置编码，由 Transformer 编码跨时间上下文，最终保留 5 秒级 128 维表征。通道掩码用于忽略填充项，使模型能在训练设计上兼容异构通道集合。

当前部署基座检查点配置为 8 个注意力头、6 层 Transformer、dropout 0.3；实际结构应以 `sleepfm/checkpoints/model_base/config.json` 与权重配套配置为准。

### LOO-CL 预训练目标

Leave-One-Out Contrastive Learning（LOO-CL）把某一模态的表征作为查询，把其余可用模态聚合后的表征作为正样本；其他记录/时间上下文作为负样本。训练目标是让同一睡眠片段的跨模态表征接近，并拉开不相关样本，从而学习共享生理语义，而不是依赖单一导联或人工标签。

## 下游模型

### 睡眠分期

基座模型生成的多模态时序嵌入经过通道注意力池化、上下文编码和双向 LSTM，再由线性分类头输出 Wake、N1、N2、N3、REM 五类概率。当前 API 按 5 秒步长返回分期；这与常见 30 秒临床判读窗口不同，使用者应按项目标准决定是否聚合。

### 疾病风险预测

疾病模型用双向 LSTM 汇总整夜嵌入，并将年龄与性别送入人口学特征层后拼接。多任务线性头输出各疾病的 Cox proportional hazards（CoxPH）风险分数，当前部署标签表包含 1065 个输出项。

`hazard_score` 只适合在同一模型、同一输入规则下做相对排序。它不是诊断结论，也不是经过基线风险和时间窗校准的绝对发病概率；阈值必须通过目标人群验证后确定。

## 当前服务推理链路

```text
EDF
 └─ 重采样/通道映射 → HDF5
     └─ Tokenizer + 通道池化 + Transformer → 5 秒级嵌入
         ├─ 睡眠分期 LSTM → 五类概率与汇总
         └─ 疾病 LSTM + 年龄/性别 → CoxPH 风险排序
```

完整推理会导出预处理 HDF5、嵌入 HDF5 以及所选下游结果 JSON。分步 API 可复用中间文件，模型计算结果不因是否通过网页调用而改变。

## 能力边界

- 只处理能被当前通道表识别的 EDF/HDF5；通道命名、单位和信号质量仍需数据方负责。
- 训练数据域外的人群、设备、采样方案和疾病标签可能产生分布偏移，部署前必须做外部验证。
- 输出不包含病因解释、治疗建议或确定性诊断。
- 年龄、性别编码错误会直接影响疾病风险输出；年龄必须填真实值，由服务端归一化。
- 公开研究结果不能直接视为本地数据集上的性能承诺，验收指标应通过固定测试集复算。
